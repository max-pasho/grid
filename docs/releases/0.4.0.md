GRID 0.4.0 brings GRID's look to every menu, a new tab page with a turning globe, a Google Search theme, and fixes for the browser. If you're on 0.3.x, replace GRID.app with this one; your settings, layout, widgets and browsing data carry over.

![The new tab page: a turning dot-matrix globe with city nodes, recent pages and a status readout](https://github.com/max-pasho/grid/blob/v0.4.0/docs/screenshots/new-tab.png?raw=true)

## Install
1. Download **GRID-0.4.0-macOS.zip**, unzip it, and move **GRID.app** to Applications (replace the old one if asked).
2. This build isn't notarized by Apple yet, so macOS blocks it the first time. Open it once, then go to **System Settings › Privacy & Security** and click **Open Anyway** (you only need to do this once).
3. Optional: check the download against **GRID-0.4.0-macOS.zip.sha256** with `shasum -a 256 GRID-0.4.0-macOS.zip`.

**Requires macOS 15** (browser extensions need macOS 15.4). Built for Apple silicon.

## What's new

### Menus in GRID's style
- **Right-click menus** in Files, Apps, terminal and browser tabs and the Recent Files widget, and the **⋯ menus** on the deck, widgets, browser and panel headers, are now drawn in GRID's design: angled frame, monospaced rows, an accent bar on the highlighted row, key-cap shortcuts and ▸ submenus. They follow your theme.
- They work like normal macOS menus: arrow keys, Return, Esc, type a letter to jump, press-drag-release, submenus, and they close when you click elsewhere or switch apps.
- **A terminal menu:** right-click the terminal for Copy, Paste, Select All, Clear Scrollback, Split, Show Directory in Files, Find and Close Pane. Programs that use the mouse (vim, htop, tmux) still get their right-clicks; Shift+right-click always opens GRID's menu.
- **Web pages** keep their usual items (Open Link in New Window, Copy Link, Look Up and so on), drawn in GRID's style.
- Prefer the standard look? **Settings › Effects** switches back to macOS menus. VoiceOver always gets standard menus.

### New tab page
- New tabs open on a slowly turning dot-matrix globe with city nodes, next to your recent pages and a status readout (time, tabs, ad blocking, themes, search engine).
- The globe is drawn by the graphics chip and only turns while you're looking at it: about 4% CPU while it turns, nothing when it's hidden, the window isn't focused, or Motion is off. It uses no location or network data; it simply starts facing your time zone.

### Google Search theme
- Google's home page and search results can now take GRID's colours and type, like GitHub, Hacker News, MDN, Wikipedia and Stack Overflow. Turn it on with the 🎨 button. Maps, Gmail and Docs are never themed.

## Fixes
- **⌘W in the browser no longer quits GRID.** It closes the current tab, and with no tabs left it returns to the terminal.
- **No stray Services menu** after right-clicking selected text in a web page, and the next click works normally.
- **Long menu items** like "Show Directory in Files" are no longer cut off with "…".

## Privacy
Unchanged: no accounts, telemetry or cloud services. Settings, history and browsing data stay on your Mac. The only network requests GRID makes on its own are downloading ad-blocking filter lists from their publishers (when ad blocking is on) and Safari's standard fraudulent-site check in the browser.

## Known limitations
- Not notarized yet (see Install).
- Text fields (address bar, palette, rename) still show the standard Cut/Copy/Paste menu.
- Parts of the Google theme rely on names Google changes from time to time; when that happens those parts stop applying until GRID is updated, and the page keeps working.
- Some ads that uBlock Origin removes with page scripts (for example on YouTube) can't be blocked with Safari's engine.
