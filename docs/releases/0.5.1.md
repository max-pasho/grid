GRID 0.5.1 can tell you when a new version is out. It checks GitHub once a day, but only if you agree. When there's an update, it can download and verify it for you. If you're on 0.5.0, replace GRID.app with this one; your settings, layout, widgets and browsing data carry over.

This is the last update you'll need to fetch by hand: from 0.5.1 on, GRID tells you about new versions itself.

![Settings › Updates showing an available version, its release notes and the Download & Verify button](https://github.com/max-pasho/grid/blob/v0.5.1/docs/screenshots/updates.png?raw=true)

## Install
1. Download **GRID-0.5.1-macOS.zip**, unzip it, and move **GRID.app** to Applications (replace the old one if asked).
2. This build isn't notarized by Apple yet, so macOS blocks it the first time. Open it once, then go to **System Settings › Privacy & Security** and click **Open Anyway** (you only need to do this once).
3. Optional: check the download against **GRID-0.5.1-macOS.zip.sha256** with `shasum -a 256 GRID-0.5.1-macOS.zip`.

**Requires macOS 15** (browser extensions need macOS 15.4). Built for Apple silicon.

## What's new

### Update checks
- **It asks first.** After you update, the status bar asks: *Check GitHub daily for GRID updates?* Choose **Check daily** or **Not now**. Nothing is checked until you answer, and you can change it any time in **Settings › Updates**.
- **Check on demand:** **GRID › Check for Updates…** or the palette's **Check for Updates** checks right away and tells you the result.
- **When a new version is out,** the status bar shows **◆ GRID x.y.z AVAILABLE** once. **View** opens **Settings › Updates** at the release: the version, the date and its release notes, with **View on GitHub**, **Download & Verify**, **Skip** and **Later** (no reminder for 7 days).
- **Download & Verify:**
  - GRID asks before downloading, then saves the zip to Downloads, marked as downloaded from the internet like any browser download.
  - It checks the zip against the SHA-256 published with the release. If they don't match, the zip goes to the Trash.
  - It unzips the zip and makes sure it contains exactly GRID.app at the expected version.
  - It shows the new app in Finder. Quit GRID and replace the app in Applications.
- **GRID never replaces itself.** macOS still asks for **Open Anyway** after each update, until releases are notarized.

## Privacy
- **New network request (only if you turn it on):** at most one request a day to `api.github.com`. It sends only a generic "GRID" user agent: no version number, account, token or install ID. When nothing has changed, GitHub just confirms that, without resending the release data. You can also check by hand at any time.
- **GitHub's answer is treated as untrusted data.** A release whose links point anywhere other than `github.com/max-pasho/grid` is ignored. Release notes are shown as plain text with no images, and their links open only when you click them.
- **Unchanged:** no accounts, telemetry or cloud services, and settings, history and browsing data stay on your Mac.

## Known limitations
- Not notarized yet (see Install).
- The SHA-256 check catches a damaged or incomplete download, but it can't prove who published the release. A one-click, signature-checked install will come once releases are signed and notarized.
- Only 0.5.1 and later can check for updates; earlier versions need this one installed by hand.
