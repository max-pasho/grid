A small bug-fix update to [0.3.0](https://github.com/max-pasho/grid/releases/tag/v0.3.0). If you already run 0.3.0, replace GRID.app with this one; your settings, layout, widgets and browsing data carry over.

## Install
1. Download **GRID-0.3.1-macOS.zip**, unzip it, and move **GRID.app** to Applications (replace the old one if asked).
2. This build isn't notarized by Apple yet, so macOS blocks it the first time. Open it once, then go to **System Settings › Privacy & Security** and click **Open Anyway** (you only need to do this once).
3. Optional: check the download against **GRID-0.3.1-macOS.zip.sha256** with `shasum -a 256 GRID-0.3.1-macOS.zip`.

**Requires macOS 15** (browser extensions need macOS 15.4). Built for Apple silicon.

## Fixes
- **No more freeze when the window is bigger than the screen.** If GRID's window ended up wider than your display (for example after unplugging an external monitor), showing the Widget Deck could lock the app at 100% CPU until macOS closed it. GRID now handles oversized windows without getting stuck.
- **The browser's address bar always shows the page you're on.** With the address field focused (as it is in a new tab), opening a page from the terminal or the command palette could leave the previous site's address showing. The address now always follows the page, and anything you've typed yourself is still kept until you press Return or Esc.

## Also new
- A refreshed [README](https://github.com/max-pasho/grid#readme) with new screenshots, install steps and a feature tour.

## Privacy
Unchanged: no accounts, telemetry or cloud services. Settings, history and browsing data stay on your Mac. The only network requests GRID makes on its own are downloading ad-blocking filter lists from their publishers (when ad blocking is on) and Safari's standard fraudulent-site check in the browser.

## Known limitations
- Not notarized yet (see Install).
- Some ads that uBlock Origin removes with page scripts (for example on YouTube) can't be blocked with Safari's engine.
- Extension popups show the extension's own design.
