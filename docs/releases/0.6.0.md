**Pre-release.** GRID 0.6.0 adds a **Map** page in GRID's style, showing licence-plate reader (ALPR) cameras mapped by OpenStreetMap volunteers. You download cameras for the regions you choose and keep them offline. Please try it and report problems. If you're on 0.5.x, replace GRID.app with this one; your settings, layout, widgets and browsing data carry over.

![The Map page: Providence tilted in 3D, glowing roads, wireframe buildings and ALPR camera reticles, with the Layers and Regions column](https://github.com/max-pasho/grid/blob/v0.6.0/docs/screenshots/map.png?raw=true)

## Install
1. Download **GRID-0.6.0-macOS.zip**, unzip it, and move **GRID.app** to Applications (replace the old one if asked).
2. This build isn't notarized by Apple yet, so macOS blocks it the first time. Open it once, then go to **System Settings › Privacy & Security** and click **Open Anyway** (you only need to do this once).
3. Optional: check the download against **GRID-0.6.0-macOS.zip.sha256** with `shasum -a 256 GRID-0.6.0-macOS.zip`.

**Requires macOS 15** (browser extensions need macOS 15.4). Built for Apple silicon.

Because this is a pre-release, GRID's update checker offers it only if **Settings › Updates › Include pre-releases** is on.

## What's new

### Map (⌥⌘5)
- **The map is drawn on the graphics chip in GRID's style:**
  - glowing roads, brightest on motorways
  - a faint grid floor over dark land, and the darkest water
  - place and street labels in GRID's type
  - **tilt to see buildings as wireframe volumes:** two-finger rotate or ⌥-drag, or the 3D button
  
  It follows your theme (Legacy, Ares, ENCOM) and Effects › Glow. It only draws when something changes, so it uses no CPU while you're not moving it.
- **Getting around:** scroll to pan, ⌘-scroll or pinch to zoom, two-finger rotate to turn. You can also use the arrow keys, + and −, and 0 to reset north.
- Settings is now page **06** (⌘, as before).

### ALPR cameras by region
- **Pick what to download:** **Add Region…** lists US states, Canadian provinces and other countries' regions, or you can **Draw Area** and ⇧-drag a rectangle on the map.
- **Before anything downloads,** GRID shows the host, the number of requests and the approximate size. Downloaded regions stay on your Mac and work offline. You can update, cancel or remove each one.
- **Sources:** cameras in the US and Canada come from DeFlock's camera tiles; GRID fetches only the parts of a region that hold cameras. Elsewhere, cameras come from an Overpass server, one request at a time.
- **On the map:** each camera is a reticle with its facing direction. Zoomed out, they gather into counted clusters. Click one for its vendor, operator, facing, mount, last edit and OpenStreetMap entry. **List** gives an accessible table of the cameras in view.
- **Settings › Updates** shows how current each region is. The check runs at most daily, and only while you use the Map.

### Locate
- **⌖ Locate** centres the map on you. GRID explains first, then macOS asks once. Your position stays in memory only: it's never saved (even with "Remember the last map view" on), logged or sent by GRID.

## Privacy
- **The Map is off until you turn it on.** It makes no network requests before you click **Enable Map Data**. After that:

| Host | When | What it learns |
|---|---|---|
| tiles.openfreemap.org | While the map is visible | Roughly where you're looking (the map tiles you view) |
| download.geofabrik.de | When you open the region list | That you opened it |
| deflock.dontgetflocked.com | When you download or check a US or Canadian region | Which region you downloaded |
| Your Overpass server | When you download a region outside the US and Canada | Which area you downloaded |

- **Unchanged:** no accounts, telemetry or cloud services. Map data is stored in Application Support, and **Settings › Map › Clear Map Data** removes it all.

## Known limitations
- Not notarized yet (see Install).
- **Camera data** is only as complete and current as OpenStreetMap's volunteers have made it.
- **Map display:**
  - When the map is tilted all the way, tiles at the far edge can occasionally be missing.
  - The cameras' facing wedges don't tilt with the ground.
  - The map has no right-click menu yet.
- **Downloads:** a rectangle drawn just outside the US uses the US source, so it finds no cameras there.
- **Locate** hasn't been tested on a Developer-ID-signed build.
- **Not included yet:** search, traffic, routing and print export.
