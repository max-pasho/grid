**Pre-release.** GRID 0.9.0 adds **places and search** to the Map. Shops, food, stops, sights and more show on the map as small icons, and a search box finds places, streets and shops. Typing searches only what's already on your Mac; searching online happens only when you ask. Please try it and report problems. If you're on 0.8.0, replace GRID.app with this one; your settings, layout, widgets, browsing data and downloaded map regions carry over.

![The Map tilted over Zermatt: place icons with their names, a diamond pin on the chosen place, and the Place card in the side column](https://github.com/max-pasho/grid/blob/v0.9.0/docs/screenshots/places.jpg?raw=true)

## Install
1. Download **GRID-0.9.0-macOS.zip**, unzip it, and move **GRID.app** to Applications (replace the old one if asked).
2. This build isn't notarized by Apple yet, so macOS blocks it the first time. Open it once, then go to **System Settings › Privacy & Security** and click **Open Anyway** (you only need to do this once).
3. Optional: check the download against **GRID-0.9.0-macOS.zip.sha256** with `shasum -a 256 GRID-0.9.0-macOS.zip`.

**Requires macOS 15** (browser extensions need macOS 15.4). Built for Apple silicon.

Because this is a pre-release, GRID's update checker offers it only if **Settings › Updates › Include pre-releases** is on.

## What's new since 0.8.0
- **Places on the map.** Zoomed into a town or city, places show as small icons beside their names. Street names still come first when space is tight.
  - **Categories:** food, shops, fuel, transit, health, lodging, parks, sights, services and other.
  - **Filtering:** the new **Places** layer in the side column has a chip for each category, to show or hide it.
  - **Clicking an icon** opens a **Place** card with what it is, its coordinates, and buttons for Apple Maps, OpenStreetMap and copying the coordinates.
- **Search places** with the box at the map's top left, or **⌘F** on the Map page.
  - **Typing** searches the place, street and shop names in the map already on your Mac. Accents don't matter ("tasch" finds Täsch), and better and nearer matches come first.
  - **Choosing a result** (click, or ↑/↓ and Return) moves the map there and drops a diamond pin with the name. **Esc** closes the list.
  - **Searching online:** press **Return** when nothing matches, **⌘Return**, or choose **Search online for …**. GRID asks the first time.

## Privacy
- **Typing never leaves your Mac.** Local search only reads map tiles you've already downloaded.
- **Online search** uses Nominatim, OpenStreetMap's search server (nominatim.openstreetmap.org by default). It's separate from **Enable Map Data**:
  - It only runs when you press Return or choose Search Online, never while you type.
  - It asks before the first search.
  - It sends at most one request a second.
  - Answers are kept in memory for up to a day. Searches are never saved or logged.
  - **Settings › Map** can turn it off or point it at another Nominatim server.

| Host | When | What it learns |
|---|---|---|
| nominatim.openstreetmap.org (or your server) | When you search online | What you searched for and roughly where you're looking |

- **Unchanged:** every other map host, and no accounts, telemetry or cloud services.

## Known limitations
- Not notarized yet (see Install).
- **Local search** only finds names in parts of the map you've loaded this session. Search online for anywhere else.
- **Place data** is only as complete as OpenStreetMap. Opening hours, phone numbers and ratings aren't shown; **Apple Maps** in the Place card has them.
- **Online answers** are reused only for the same search from the same view; moving the map and searching again sends a new request.
- **Not included yet:** traffic, routing and print export.
