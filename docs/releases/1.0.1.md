GRID 1.0.1 follows the project to its new home: the GitHub account was renamed from **HackitM** to **max-pasho**, so GRID now lives at [github.com/max-pasho/grid](https://github.com/max-pasho/grid). Nothing else changes. If you're on 1.0.0, replace GRID.app with this one; your settings, layout, widgets, browsing data and downloaded map regions carry over.

**Fetch this one by hand.** GRID 1.0.0 only trusts releases from the old address, so it ignores this update and keeps saying it's up to date. From 1.0.1 on, update checks work again.

## Install
1. Download **GRID-1.0.1-macOS.zip**, unzip it, and move **GRID.app** to Applications (replace the old one if asked).
2. This build isn't notarized by Apple yet, so macOS blocks it the first time. Open it once, then go to **System Settings › Privacy & Security** and click **Open Anyway** (you only need to do this once).
3. Optional: check the download against **GRID-1.0.1-macOS.zip.sha256** with `shasum -a 256 GRID-1.0.1-macOS.zip`.

**Requires macOS 15** (browser extensions need macOS 15.4). Built for Apple silicon.

## Fixes
- **Update checks use the new address.** GRID asks GitHub about `max-pasho/grid` and accepts only releases whose links point there. A release from the old `HackitM/grid` address is ignored, so whoever registers that name later can't offer GRID an update.
- **Map requests** name the new project address in their user agent.

## Privacy
Unchanged: no accounts, telemetry or cloud services. The update check is still at most one request a day to `api.github.com`, only if you turned it on.
